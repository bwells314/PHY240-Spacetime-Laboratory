Minkowski spacetime diagram · Frame S coordinates

Horizontal axis: position in the selected frame; vertical axis: ct in the same distance units. Light rays travel at 45° when both axes use equal scales. Blue: spacecraft worldline; yellow: radio or laser signal. Green dashed: constant S time; orange dashed: constant S′ time. Each line is transformed into the selected plotting coordinates. Both can be toggled independently. The two coordinate grids show constant-position and constant-time lines in their respective frames.

Equations and activity questions

PHY 240 · Teaching simulation. All distances and times are idealized; accelerations are neglected except where explicitly modeled. Both panels use independent coordinate clocks advancing at the same numerical rate; named events occur at different playback moments in S and S′. Use Event buttons to inspect event coordinates. Animations are not photographic appearances including light-travel delay. Time is in years or months; distance is in corresponding light-units, so c = 1.
